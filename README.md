# my-site

Source code for my personal portfolio website.

## Overview

A clean single-page site showcasing my projects, interests, and contact links:

- **[JD Launcher](https://github.com/xxeisenberg/jd-launcher)** – Minecraft launcher built with Tauri, Rust, and React.
- **[Sudoku CLI](https://github.com/xxeisenberg/sudoku)** – Terminal Sudoku game with a keyboard-driven TUI.
- **[Drop](https://github.com/xxeisenberg/drop)** – Zero-install terminal file sharing tool.
- **[x44](https://github.com/xxeisenberg/x44)** – Static site deployment platform.

## Tech Stack

- HTML5 & CSS3
- Tailwind CSS v4 (`@tailwindcss/browser`)
- Google Fonts (_Instrument Serif_, _Quintessential_)

## Running Locally

No build step required. Open `index.html` directly or serve it with any static HTTP server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
